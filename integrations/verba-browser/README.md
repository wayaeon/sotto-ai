# Verba Local Context for Chrome and Edge

This optional unpacked extension sends only the active hostname and the focused-field category to the Verba app on `127.0.0.1:38471`. It does not read page text, email bodies, screenshots, audio, or credentials.

1. Run Verba.
2. Open `chrome://extensions` or `edge://extensions` and enable Developer mode.
3. Select **Load unpacked** and choose this folder.

Chrome/Edge show the extension's broad website access because it must identify the current site and focused field. The extension sends no page contents.
